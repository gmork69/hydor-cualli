🧩 El ESP y el ADS van a caballo sobre el canal central: una fila de patitas arriba y la otra abajo. Así cada pata cae en su propia columna y no hacen corto.
⚠️ Une los dos rieles de GND (–). En casi todas las protoboards el riel de arriba y el de abajo no están conectados entre sí. El ESP y el ADS usan el de arriba; el MQ-135 y la R2 usan el de abajo. Pon un cable negro del riel – de arriba al riel – de abajo (en el dibujo, a la derecha). Sin ese cable el MQ-135 no comparte tierra con el ADS y la lectura de A1 sale loca.

🔍 Zoom: cómo van las 2 RESISTENCIAS (no capacitores) en el protoboard

💡 Truco del protoboard: los 5 hoyos de una misma columna están conectados entre sí. R1 y R2 comparten la columna B — ahí se tocan y forman el punto medio. De esa columna sale el cable a A1, y R2 la baja a GND. La columna A solo recibe la señal del MQ-135. Son resistencias, no capacitores.

🧑‍💻 Código para el Arduino IDE (leer A0 = agua, A1 = aire)

// Librería: "Adafruit ADS1X15" (instálala desde el gestor de bibliotecas)
#include <Wire.h>
#include <Adafruit_ADS1X15.h>

Adafruit_ADS1115 ads;

void setup() {
  Serial.begin(115200);
  Wire.begin(4, 5);        // SDA = D2 (GPIO4), SCL = D1 (GPIO5)
  ads.setGain(GAIN_ONE);   // rango cómodo para 0–3.3V
  ads.begin(0x48);         // ADDR a GND = dirección 0x48
}

void loop() {
  int16_t a0 = ads.readADC_SingleEnded(0);   // A0 = TDS (agua)
  int16_t a1 = ads.readADC_SingleEnded(1);   // A1 = MQ-135 (aire)

  float vAgua = ads.computeVolts(a0);
  float vAire = ads.computeVolts(a1) * 2.0;  // x2 deshace el divisor 10k+10k

  Serial.printf("Agua A0: %.3f V  |  Aire A1: %.3f V\n", vAgua, vAire);
  delay(2000);
}
